\section{实施结论}
本轮按 P0 到 P1 顺序完成跨语言契约、SQLite 持久化与迁移、中断恢复、下载配额、全源搜索、阅读器、本地书库、诊断脱敏和质量门重构。原有启动入口、HTTP 路径、必填入参、任务流程及既有返回字段保持不变，新增字段均为可选字段。

本轮未执行电脑重启、Docker 重启、项目服务强制重启、系统安装或系统修复。API 回归测试仅使用随机端口的隔离子进程。

\section{后续边界}
审核、基础设施、来源管理、备份恢复应消费公共服务，不在页面组件内复制业务逻辑。Tauri、WebDAV、插件市场和 PDF 专用渲染属于 P2；任何新增下载、安装或可能触发环境与服务重启的操作，必须先说明影响并取得用户明确同意。
